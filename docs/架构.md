# 架构

## 一条消息是怎么走到 QQ 的

```
① 用户在 QQ 里发消息
        ↓
② SnowLuma 注入 QQ 客户端，把消息转成 OneBot v11 事件
   → WebSocket ws://127.0.0.1:3001
        ↓
③ qq-bridge 收到事件
   - 判断要不要叫醒她（@ / 名字 / 提问 / 关键词 / 概率）
   - 把消息写进会话状态（socialV2）
        ↓
④ 桥接调 DSH 的 HTTP API，把一条【唤醒】提示投进 DSH 会话
   （这时她的上下文里多了一段：会话令牌 + 唤醒原因 + 行动指令）
        ↓
⑤ DSH 里她开始一个回合：
   - 能看到未读消息、角色卡、工具列表
   - 决定说什么、要不要调工具
        ↓
⑥ 她说的话要通过工具发出去（文本输出不会自动发送）
   qq_send_message / qq_reply / qq_send_voice / qq_send_sticker
        ↓
⑦ 桥接调 OneBot API 发出去 → 用户收到
```

**关键点**：她的文本输出**不会自动发到 QQ**。必须调工具。这是二代仿真模式的设计。

## DSH 侧的 MCP 配置

`<DSH profile>/cordis.patch.yml`，每个 MCP 一个 `insert`：

```yaml
- insert:
    - id: mcp-voice
      name: '@deepseek-ai/dsh-mcp-client'
      config:
        serverName: voice
        transport: stdio
        command: 'C:\Program Files\nodejs\node.exe'
        args: ['<repo>\voice\mcp-voice-server.js']
        env:
          VOICE_DAEMON_URL: 'http://127.0.0.1:8848'

    - id: mcp-phone
      name: '@deepseek-ai/dsh-mcp-client'
      config:
        serverName: phone
        transport: stdio
        command: 'C:\Program Files\nodejs\node.exe'
        args: ['<path-to>\ai-companion-kit\packages\phone-mcp\src\phone-mcp.js']
        env:
          PHONE_ADB: 'F:\MuMuPlayer\nx_main\adb.exe'
          PHONE_SERIAL: '127.0.0.1:16384'
          PHONE_SHOT_DIR: '<repo>\photos'
          PHONE_PYTHON: '<python>'
          PHONE_SHRINK_SCRIPT: '<repo>\voice\shrink-shot.py'
          PHONE_FFMPEG: 'F:\ffmpeg\bin\ffmpeg.exe'
        toolCallTimeoutMs: 300000
```

**改完必须重启 DSH**（MCP 服务在启动时 spawn）。

## 工具白名单

`plugins/qq-agent-presets/qq-tool-restrict.mjs` 是个 DSH 插件，在工具调用前拦截：

```js
const SAFE_PREFIXES = [
  'mcp__snowluma__',   // QQ 读写
  'mcp__diary__',      // 日记
  'mcp__voice__',      // 语音
  'mcp__phone__',      // 手机
  'mcp__bili-duty__',  // B站（只读）
  // ...
];
```

**默认拒绝**，只放行列表里的。危险工具（发评论、跑脚本、登录）不在里面。

运行时补充（免重启）：

```json
// state/tool-allow-extra.json
{ "prefixes": ["mcp__phone__"], "exact": ["bili_cover"] }
```

## 后台循环

| 任务 | 周期 | 脚本 |
|---|---|---|
| DSH 端口跟随 | 60s | `follow-dsh-port.cmd` |
| 健康检查 + 自愈 | 2min | `watchdog-loop.cmd` → `check-bot-health.ps1` |
| 记忆同步 | 20min | `sync-memory-loop.cmd` → `sync-shared-memory.py` |
| 备份 | 20min + 开机 | `backup-bot-state.ps1` |
| 主动机会 | 30–90min | 桥接内置 |
| 她自己的生活 | 1h | 桥接内置（见 `她自己的生活.md`） |

**都通过 VBS 隐藏窗口启动**，避免桌面上挂一堆黑框。
