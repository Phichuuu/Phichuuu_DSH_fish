# 语音链路

三条链路，按"自然度"从高到低排，前一条挂了自动退下一条。

```
voice_say(text, mode?, style?, speed?, pitch?)
   │
   ├─① MiniMax speech-2.8-hd（主，说话）
   │      voice: female-shaonv 等系统音色
   │      emotion: happy / sad / angry / neutral…
   │      → hex 音频，注意不是 base64
   │
   ├─② MiMo mimo-v2.5-tts / voiceclone（备，唱歌）
   │      预置音色 + (唱歌) 标签
   │      voiceclone 要 DataURL（data:audio/wav;base64,...）
   │
   └─③ 本地 RVC（兜底）
          edge-tts 合成 → RVC 换音色
          冷启动慢，音质取决于模型
```

---

## ① MiniMax

**为什么放第一位**：系统音色是真人录制的，自然度明显高一档。

请求（`POST https://api.minimax.cn/v1/t2a_v2`）：

```json
{
  "model": "speech-2.8-hd",
  "text": "主人主人，你看我今天乖不乖呀",
  "stream": false,
  "voice_setting": {
    "voice_id": "female-shaonv",
    "speed": 1.05,
    "vol": 1.0,
    "pitch": 2,
    "emotion": "happy"
  },
  "audio_setting": {
    "sample_rate": 32000,
    "bitrate": 128000,
    "format": "mp3",
    "channel": 1
  }
}
```

**坑：**

| 坑 | 表现 | 修法 |
|---|---|---|
| 音频是 **hex** 不是 base64 | `base64.b64decode` 报错 / 音频坏 | `bytes.fromhex(data)` |
| `emotion` 只认枚举 | 传中文直接 400，整条链掉到兜底 | 先映射（温柔→neutral，委屈→sad） |
| 免费额度有限流 | 连发几条返回 429 | 等 30–60 秒，或做排队 |

## ② MiMo（小米）

**为什么留它**：它支持 `(唱歌)` 标签，是这套里唯一能唱歌的。

```json
{
  "model": "mimo-v2.5-tts",
  "messages": [
    { "role": "user", "content": "活泼俏皮，像跟熟人聊天" },
    { "role": "assistant", "content": "(唱歌)一闪一闪亮晶晶" }
  ],
  "audio": { "format": "wav", "voice": "冰糖" }
}
```

**坑：**

| 坑 | 表现 | 修法 |
|---|---|---|
| 克隆要 **DataURL** | `audio.voice must be a DataURL` | `data:audio/wav;base64,<...>` |
| 文字设计音色依赖描述 | 描述写太细会"演"，听起来假 | 写口语（"像微信发语音那样随口说"），别写技术参数 |
| 不支持边克隆边唱歌 | voiceclone 无法 sing | 唱歌用预置音色 |

## ③ 本地 RVC

`edge-tts` 合成 → RVC 换音色 → 输出 wav。

**这条链的根本问题**：RVC 是"换音色"，不是"合成声音"。
它保留**源音频的节奏和呼吸**——而 TTS 的源音频没有呼吸、节奏过于均匀。
所以**用假嗓子换音色，出来还是假嗓子**。

它对参数也敏感：

```python
index_rate   # 官方推荐 0.3（拉高会"像"但出金属味）
protect      # 0.33
rms_mix_rate # 1.0
```

**什么时候还留着它**：前面两条都没 key、或者都用不了的时候。
冷启动约 50 秒（加载模型），热了 5–10 秒一句。

## 截图压缩（给"看图"用）

手机截图 900×1600 的 PNG ≈ 1.3–2.5 MB，base64 之后 ×1.33。
一个图片块就能吃掉好几万 token。

`voice/shrink-shot.py`：长边 ≤ 900，JPEG 质量 80 → **60–250 KB**。

```bash
python shrink-shot.py in.png out.jpg
```

在 `phone-mcp` 的 `phone_screenshot` 里调用（见 `phone/patches/`）。

## 环境变量

| 变量 | 作用 |
|---|---|
| `MINIMAX_KEY_FILE` | key 文件路径（默认 `<repo>/minimax-key.txt`） |
| `MIMO_KEY_FILE` | 同上 |
| `VOICE_DAEMON_URL` | 老链路地址（默认 `http://127.0.0.1:8848`） |
| `FEIYU_DAEMON_URL` | CosyVoice 地址（默认 `8850`→ `8849`） |
| `PHONE_PYTHON` / `PHONE_SHRINK_SCRIPT` | 截图压缩用的解释器和脚本 |
