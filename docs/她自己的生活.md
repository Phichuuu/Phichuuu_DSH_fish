# 她自己的生活：定时静默唤醒

## 问题

qq-bridge 的自动唤醒只有三种：

1. 有人说话 / @ / 叫名字
2. 回复检查（刚才发过消息，回来看有没有人接）
3. 群冷场（主动冒泡机会）

**私聊里没有第四种。** 所以角色卡里写再多"你可以自己发说说、写日记、玩手机"，
只要没人叫，她就不会动 —— 因为她没有"想起来"的时刻。

## 解法

加一条唤醒原因 `ownLife`，每约 1 小时投递一次，内容是"现在是你的时间"。

**静默**：不往 QQ 发任何东西，只是把一段提示塞进她的上下文。

---

## 代码

### 1. 唤醒文案（改 `bridge.js` 的 prompt 构造函数）

在 `poke` 分支后面加：

```js
if (reason === 'ownLife') {
  return `${base}【你自己的时间】${key}
现在这一段没有人找你，也不是谁在等回话——这是你自己的一段时间。

你可以：
- 拿起手机玩一会儿：phone_open_app("com.android.chromium") 上网，或者 phone_screenshot 看看桌面
- 写一条日记（别写已经写过的角度）
- 发一条说说（先 qzone_my_posts 看看今天发过没）
- 什么都不干，发呆也行

【分寸】主人没在等你汇报。深夜或他大概睡了的时段，别拿小事去打扰他。`;
}
```

### 2. 定时器

```js
let ownLifeTimer = null;

function ownLifeStatePath() {
  return path.join(STATE_DIR, 'own-life.json');
}

function readOwnLifeState() {
  try { return JSON.parse(fs.readFileSync(ownLifeStatePath(), 'utf8')) || {}; }
  catch { return {}; }
}

function writeOwnLifeState(next) {
  try {
    fs.mkdirSync(STATE_DIR, { recursive: true });
    fs.writeFileSync(ownLifeStatePath(), JSON.stringify(next, null, 2), 'utf8');
  } catch (e) { log('[own-life] 状态写不进去:', e?.message ?? e); }
}

function startOwnLifeScheduler() {
  if (ownLifeTimer) return;
  const cfgOwn = cfg.socialV2?.ownLife ?? {};
  if (cfgOwn.enabled === false) return;

  const intervalMs = Math.max(20 * 60 * 1000, Number(cfgOwn.intervalMs) || 60 * 60 * 1000);
  const maxPerDay = Math.max(1, Number(cfgOwn.maxPerDay) || 10);
  const quietFrom = Number(cfgOwn.quietFrom ?? 2);
  const quietTo = Number(cfgOwn.quietTo ?? 8);

  const tick = async () => {
    try {
      if (currentMode !== 'reserved2' || socialV2.paused) return;
      const ownerKey = `private:${cfg.ownerQQ}`;

      const now = Date.now();
      const st = readOwnLifeState();
      const day = new Date(now).toISOString().slice(0, 10);
      const firedToday = st.lastDay === day ? Number(st.firedToday || 0) : 0;
      const hour = new Date(now).getHours();
      const inQuiet = quietFrom <= quietTo
        ? hour >= quietFrom && hour < quietTo
        : hour >= quietFrom || hour < quietTo;

      if (inQuiet) return;
      if (firedToday >= maxPerDay) return;
      if (now - Number(st.lastFiredAt || 0) < intervalMs) return;

      const conv = socialV2.conversations.get(ownerKey);
      if (conv && isConversationBusyV2(ownerKey, conv)) return;  // 别打断正事

      await sendWakePromptV2(ownerKey, 'ownLife');
      writeOwnLifeState({ lastFiredAt: now, lastDay: day, firedToday: firedToday + 1 });
      log(`[own-life] 给了她一段自己的时间（今天第 ${firedToday + 1} 次）`);
    } catch (error) {
      log('[own-life] 异常:', error?.message ?? error);
    } finally {
      ownLifeTimer = setTimeout(tick, 10 * 60 * 1000);   // 每 10 分钟看一次
      ownLifeTimer.unref?.();
    }
  };

  ownLifeTimer = setTimeout(tick, 5 * 60 * 1000);
  ownLifeTimer.unref?.();
}
```

### 3. 挂上去

在桥接确认 `reserved2` 模式的地方（`DSH 已就绪` 之后）调用：

```js
log('桥接模式已确定为 reserved2，恢复有限睡眠定时器');
startOwnLifeScheduler();
```

## 配置

`config.json`：

```json
{
  "socialV2": {
    "ownLife": {
      "enabled": true,
      "intervalMs": 3600000,
      "maxPerDay": 10,
      "quietFrom": 2,
      "quietTo": 8
    }
  }
}
```

| 字段 | 说明 |
|---|---|
| `intervalMs` | 两次之间至少隔多久（最小 20 分钟） |
| `maxPerDay` | 一天最多叫几次 |
| `quietFrom` / `quietTo` | 安静时段，跨零点也支持（比如 22→6） |

---

## 设计取舍

| 约束 | 为什么 |
|---|---|
| **静默** | 唤醒不该在 QQ 上产生任何消息，否则就成了"定时发帖机器人" |
| **有配额** | 一天叫 20 次她会烦，你也会烦 |
| **状态落盘** | 关机再开机不能一次补发一堆 |
| **忙时不打断** | 她正在回合里，再塞一条会打架 |
| **可关** | `enabled: false` 立即停 |

## 手动触发（调试用）

```bash
curl -X POST http://127.0.0.1:3100/api/socialV2/wake \
  -H "X-Console-Token: <token>" \
  -H "Content-Type: application/json" \
  -d '{"key":"private:10001","reason":"ownLife"}'
```

调试时会被排进队列（如果会话正忙），日志里能看到：

```
[reserved2] 会话繁忙，暂存唤醒原因 private:10001（ownLife@seq58，原因=turn）
```
