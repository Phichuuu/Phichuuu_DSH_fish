按"坑 → 现象 → 原因 → 修法"写。都是真踩过的。

## 一、进程与热更新

### 1. 改了 MCP 服务代码，AI 那边没反应

**现象**：改完 `mcp-voice-server.js`，AI 调工具还是老行为。

**原因**：MCP 服务是 DSH **启动时 spawn** 的常驻进程，改文件不会重载。

**修法**：杀掉那个 node 进程，DSH 会在下次需要时重新拉起：
```powershell
Get-CimInstance Win32_Process -Filter "Name='node.exe'" |
  Where-Object { $_.CommandLine -match 'mcp-voice' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
```

### 2. 工具白名单改了不生效

**现象**：往 `qq-tool-restrict.mjs` 的白名单里加了工具，AI 还是说"不在白名单"。

**原因**：那个文件在 DSH 启动时被读进内存，改文件不影响已运行的进程。

**修法**：加一层**运行时 JSON**（每 5 秒读一次），优先级高于代码里的列表：
```
state/tool-allow-extra.json
{ "prefixes": ["mcp__voice__", "mcp__phone__"], "exact": [] }
```

### 3. 一把梭 `Stop-Process -Name node` 会把别的服务带崩

**现象**：想重启桥接，结果 QQ 网关也断了。

**原因**：SnowLuma / 桥接 / MCP 都是 node 进程，按名字杀会全杀。

**修法**：按 **命令行匹配** 精确杀：
```powershell
Get-CimInstance Win32_Process -Filter "Name='node.exe'" |
  Where-Object { $_.CommandLine -match 'bridge\.js' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
```

## 二、编码（Windows 上的经典三连）

### 4. `.ps1` 里有中文就解析失败

**现象**：`Unexpected token 'DOWN'`、`Missing closing ')'`，但代码看起来没问题。

**原因**：**Windows PowerShell 5.1 按 ANSI 读 `.ps1`**。UTF-8 的中文字节被误读，
引号容易"提前闭合"，于是整段语法崩掉。

**修法**：`.ps1` **只用 ASCII**。日志和输出写英文，中文放 `.md` 里。

### 5. `.cmd` 里有中文就乱码

同理，cmd.exe 读批处理也是本地代码页。**批处理只用 ASCII**。

### 6. `.vbs` 里有 UTF-8 注释直接报错

`cscript` 按 ANSI 读，中文注释能把它搞崩（"缺少对象"之类）。
**VBS 只用 ASCII**。

### 7. PowerShell 的 `>` 会破坏二进制文件

**现象**：`adb exec-out screencap -p > shot.png` 出来的图打不开，Pillow 说
`cannot identify image file`。

**原因**：PowerShell 的 `>` 是文本重定向，会改编码/换行。

**修法**：用 `adb pull`，或者
```powershell
[IO.File]::WriteAllBytes($path, $bytes)
```

## 三、DSH 相关

### 8. DSH 每次启动端口都不同 → 桥接连不上

**现象**：开机后机器人不回话，日志说连不上 DSH。

**原因**：DSH 桌面版每次启动随机选 web 端口。

**修法**：`scripts/sync-dsh-port.ps1` + `follow-dsh-port.cmd`，每 60 秒探测一次
（对 `/` 发请求，401 就说明是 DSH），变了就改 `config.json` 并重启桥接。

### 9. 重置会话会把她的记忆清空 ⚠️

**现象**：调了几次"重置会话"之后，她对你的人际印象、话题全没了。

**原因**：那个接口会**整体删除**会话状态（`activeTopics` / `memberImpressions` /
`unread`），不只是清对话上下文。

**修法**：
- 能用重启桥接解决的，别用 reset
- 无论如何：**定时备份**（`scripts/backup-bot-state.ps1`）

### 10. 她自己装了个没用的 App

**现象**：在模拟器的应用商店里点了"下载→安装"，装了个广告浏览器。

**原因**：角色卡里只写了"别乱点"，但**工具层面没有任何限制**。

**修法**（按需要选）：
- 软：在角色卡里写清楚"装 App 之前先问主人"
- 硬：`adb shell pm disable-user --user 0 com.android.packageinstaller`
  （注意：这也会挡住你自己用 UI 安装；`adb install` 不受影响）

## 四、语音

### 11. MiniMax 返回的是 hex，不是 base64

```python
raw = bytes.fromhex(data["audio"])
```

### 12. MiniMax 的 emotion 只认枚举

传"温柔"直接 400，然后整条链掉到兜底（听起来就像机器人）。
**先做中文 → 枚举的映射**。

### 13. MiMo 的 voiceclone 要 DataURL

```
audio.voice must be a DataURL for voice clone model
```

`data:audio/wav;base64,<...>`，不是裸 base64。

### 14. 音色描述写得越"专业"越假

```
❌ 带一点点鼻音和颗粒感，句末软软地拖音
✅ 像在微信里发语音那样随口说话，不要朗读感
```

模型真的会照做——"鼻音""拖音"一出来就假了。

### 15. RVC 换音色 ≠ 合成

用 edge-tts 的假嗓子喂 RVC，出来还是假嗓子。
RVC 保留**源音频的节奏与呼吸**，合成嗓没有呼吸。

参数也会坑人：`index_rate` 从 0.3 拉到 0.75 会"更像"，但带金属味。

## 五、手机

### 16. `uiautomator dump` 在安卓 15 上段错误

文件写出来了，但退出码非 0。工具的 `try/catch` 把它当失败。
**把 dump 那一步包进 try，交给后面的 `cat` 判断。**

### 17. 截图 2.5 MB 撑爆上下文

900×1600 PNG = 1.3–2.5 MB。压成 JPEG（长边 ≤ 900，质量 80）→ 60~250 KB。

### 18. 中文打不进去

`adb shell input text 中文` 静默失败。必须装 **ADBKeyboard** 并用
`am broadcast -a ADB_INPUT_TEXT --es msg <text>`。

### 19. 重启模拟器后输入法被重置

`ensureIme()` 每次输入前检查一次，不在就切回来。

## 六、网络

### 20. winget / GitHub 下载失败

**现象**：`InternetOpenUrl() failed. 0x80072efd`。

**修法**：所有 GitHub 资源走代理：
```
https://gh-proxy.com/https://github.com/...
```
pip 用国内镜像，PyTorch wheel 用 `mirrors.nju.edu.cn/pytorch/whl/cu128`。

### 21. HuggingFace 的 Xet 存储镜像不通

**现象**：`CAS Client Error: HTTP status client error (401)`。

**修法**：`HF_HUB_DISABLE_XET=1`。

## 七、系统

### 22. Windows 家庭版装不了 WSL2

**现象**：`vmcompute.exe` 根本不存在（不是没启动），`HCS_E_SERVICE_NOT_AVAILABLE`。

**原因**：家庭版 + 精简镜像里没有虚拟机平台组件。

**修法**：别硬刚。要走本地 TTS 就用原生 Windows 跑（CosyVoice 的官方仓库支持），
或者干脆用云端 TTS。

### 23. 虚拟化开了但 WSL 还是不行

`VirtualizationFirmwareEnabled = True` 只说明 CPU 支持；Windows 侧的组件缺失是另一回事。
**用 MuMu/VirtualBox 这类自带 hypervisor 的方案可以绕开。**
